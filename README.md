## Hi, I'm Karim

I build outbound systems in code. Mostly Python, Claude Code and Clay, running on GitHub Actions so they keep working when my laptop is off.

Before this I sold. I closed deals in three B2B sales jobs, and that's why I care about who ends up on a list. A list is only good if a salesperson can actually call it.

I studied software engineering at the University of Duisburg-Essen and live in Essen, Germany.

### Things I've built

**[workday-signal-agent](https://github.com/kari-fakh12/workday-signal-agent)**
Built for a global payroll-data platform. Every company that runs Workday has a public careers site on myworkdayjobs.com, so the agent searches for those, checks each company against the ICP and sends the good ones into Clay and HeyReach. It runs every morning and posts a short update to Slack. It found 242 qualified companies.

**[b2b-enrichment-engine](https://github.com/kari-fakh12/b2b-enrichment-engine)**
Built for an AI call-QA company that sells to contact centres. It finds the most senior person running the call floor, verifies a mobile number with the cheapest provider first, and dedupes against HubSpot. 481 senior contacts, 55 calls booked, 25 deals closed by their team.

**[clay-playbook](https://github.com/kari-fakh12/clay-playbook)**
How I set up four Clay systems for a payroll-data platform: Workday accounts, multinationals with their HR leaders, website visitors and new CEO/CHRO alerts. Also how I split outreach into 16 segments so every result is traceable, and my notes on using Claude Code with Clay without burning credits.

**[sdr-signal-agent](https://github.com/kari-fakh12/sdr-signal-agent)**
Finds DACH companies the week they post an SDR or BDR job, because that's when they've decided to do outbound. Built for Clayground and Arvana. Live pages: [clayground-signal.vercel.app](https://clayground-signal.vercel.app) and [arvana-signal.vercel.app](https://arvana-signal.vercel.app)

**[sandbox-intent-signals](https://github.com/kari-fakh12/sandbox-intent-signals)**
A small test: finding companies that need fast sandboxes for AI agents, from their job posts and the SDKs in their code.

**[ai-lead-qualification](https://github.com/kari-fakh12/ai-lead-qualification)**
My bachelor project. Sorts inbound lead messages into hot, warm and cold with GPT-4o-mini. 93% accuracy on 500+ test cases.

### How I work

- Every fact on a list has a source. If I can't confirm something, it says "needs check".
- If it has to run every day, it runs in the cloud, with a spend cap and a way to switch it off.
- I write a runbook so someone who isn't technical can run it without me.
